# الملف التعريفي التفاعلي – Ravel Storage

صفحة واحدة ثابتة (HTML + CSS + JavaScript) تُفتح برابط مباشر من الجوال أو الكمبيوتر، بالعربية والإنجليزية.
الافتتاحية مشي في ممر المستودع ودخول من باب الوحدة، وبعدها لكل قسم تفاعله: قفل يكشف الصورة الحقيقية، مجسّم يُدار ويُفتح مع مسطرة تُسحب لتغيير المساحة، بطاقات مميزات تُسحب، وقصة أفقية لخطوات الحجز. في النهاية يرسل الزبون طلبه على واتساب.

من يفعّل «تقليل الحركة» في جهازه يرى الصفحة ثابتة بنفس المحتوى والوظائف.

## الملفات

| الملف | ما فيه |
|---|---|
| `_src/data.json` | الأسعار، المقاسات والأبعاد وما يناسب كل مقاس، المناطق، أرقام التواصل |
| `_src/strings.json` | كل النصوص: `"المفتاح": ["عربي", "English"]` |
| `_src/template.html` | هيكل الصفحة |
| `_src/build.py` | يبني `index.html` و `assets/js/data.js` |
| `assets/css/style.css` | التصميم وألوان الهوية |
| `assets/js/app.js` | منطق الصفحة: المستكشف والمسطرة، قائمة الأسعار، دليل المساحات، رسائل واتساب، مشهد الافتتاحية |
| `assets/js/fx.js` | طبقة الحركة: تبدّل ألوان الخلفية، العناوين، القفل، رزمة البطاقات، القصة الأفقية. الصفحة تعمل بدونه |
| `assets/js/scene3d.js` | الممر والوحدة المجسّمة (Three.js) |
| `assets/img`, `assets/fonts`, `assets/vendor` | الصور الحقيقية، الخطوط، مكتبة Three.js |

`index.html` و `assets/js/data.js` ناتجان عن البناء، فلا تعدّلهما مباشرة.

## التعديل والبناء

```bash
cd profile
python3 _src/build.py          # بعد أي تعديل في _src
python3 -m http.server 8000    # للمعاينة: http://localhost:8000
```

- **تغيير سعر أو إضافة مقاس:** عدّل `sizes` في `_src/data.json`. السعر `null` يعرض «يرجى الاستفسار». قائمة «كل الأسعار» تحت المجسّم ودليل المساحات في قسم «المساحة المناسبة» يُبنيان من نفس القائمة (الدليل يجمع المقاسات المتجاورة التي لها نفس قيمة `fits`).
- **المناطق:** قائمة `branches` في `_src/data.json` (حالياً مصفح والمفرق)، وتظهر في خانة «المنطقة» في نموذج الطلب.
- **تغيير نص:** عدّل المفتاح في `_src/strings.json` باللغتين.

## النشر

المجلد يعمل على أي استضافة ملفات ثابتة (Netlify، GitHub Pages، أو مجلد داخل موقع الشركة). لا يحتاج خادماً ولا قاعدة بيانات.

لتظهر صورة المعاينة عند مشاركة الرابط في واتساب، ابنِ الصفحة بالرابط النهائي:

```bash
python3 _src/build.py --base https://example.com/profile/
```

لصفحة معاينة واحدة تعمل لحالها (الصور مدمجة داخلها):

```bash
python3 _src/build.py --artifact مجلد_الإخراج
```

## روابط مفيدة

- `index.html#en` أو `?lang=en` يفتح النسخة الإنجليزية.
- `?lite=1` يفتح الوضع الخفيف بدون مجسّمات (يُفعَّل تلقائياً على الأجهزة الضعيفة، ومن القائمة يدوياً).

## الخصوصية

الصفحة لا تجمع بيانات ولا ترسل شيئاً لأي خادم. رسالة واتساب تُعرض للزبون كاملة قبل الإرسال وفيها اختياراته فقط.
