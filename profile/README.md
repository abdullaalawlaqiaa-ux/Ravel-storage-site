# الملف التعريفي التفاعلي – Ravel Storage

صفحة واحدة ثابتة (HTML + CSS + JavaScript) تُفتح برابط مباشر من الجوال أو الكمبيوتر، بالعربية والإنجليزية.
الافتتاحية رحلة من بوابة المستودع إلى داخل الوحدة: على الهاتف فيلم مصوّر يتحرك مع السحب وينتهي على الصورة الحقيقية للوحدة C-06، وعلى الكمبيوتر ممر مجسّم. وبعدها لكل قسم تفاعله: قفل يكشف الصورة الحقيقية، مجسّم يُدار ويُفتح مع مسطرة تُسحب لتغيير المساحة، حاسبة تمتلئ بمكعبات، بطاقات مميزات تُسحب، وقصة أفقية لخطوات الحجز. في النهاية يرسل الزبون طلبه على واتساب.

من يفعّل «تقليل الحركة» في جهازه يرى الصفحة ثابتة بنفس المحتوى والوظائف.

## الملفات

| الملف | ما فيه |
|---|---|
| `_src/data.json` | الأسعار، المقاسات والأبعاد، الفروع وروابط الخرائط، أرقام التواصل |
| `_src/strings.json` | كل النصوص: `"المفتاح": ["عربي", "English"]` |
| `_src/template.html` | هيكل الصفحة |
| `_src/build.py` | يبني `index.html` و `assets/js/data.js` |
| `_src/film.py` | يقطّع فيلم الافتتاحية إلى إطارات `assets/img/film/` ويكتب `_src/film.json` |
| `_src/gen/` | أصول الصور واللقطات المولّدة بجودتها الكاملة (غير مطلوبة للاستضافة) |
| `assets/css/style.css` | التصميم وألوان الهوية |
| `assets/js/app.js` | منطق الصفحة: المستكشف والمسطرة، الحاسبة، رسائل واتساب، مشهد الافتتاحية |
| `assets/js/fx.js` | طبقة الحركة: تبدّل ألوان الخلفية، العناوين، القفل، رزمة البطاقات، القصة الأفقية، مكعبات الحاسبة. الصفحة تعمل بدونه |
| `assets/js/scene3d.js` | الممر والوحدة المجسّمة (Three.js) |
| `assets/img`, `assets/fonts`, `assets/vendor` | الصور، الخطوط، مكتبة Three.js |

`index.html` و `assets/js/data.js` ناتجان عن البناء، فلا تعدّلهما مباشرة.

## التعديل والبناء

```bash
cd profile
python3 _src/build.py          # بعد أي تعديل في _src
python3 -m http.server 8000    # للمعاينة: http://localhost:8000
```

- **تغيير سعر أو إضافة مقاس:** عدّل `sizes` في `_src/data.json`. السعر `null` يعرض «اطلب عرض سعر».
- **المناطق:** قائمة `branches` في `_src/data.json` (حالياً مصفح والمفرق). المنطقة التي قيمة `map` فيها `null` تعرض زر «أرسلوا لي الموقع» على واتساب، وإذا وضعت رابط Google Maps يظهر زر «الاتجاهات على الخريطة».
- **تغيير نص:** عدّل المفتاح في `_src/strings.json` باللغتين.

## الصور: الحقيقي والمولَّد

- **صور حقيقية من رافل (لا تُستبدل):** `corridor`، `unit-1`، `unit-6`، `unit-15`، `unit-25`، `unit-100`، والشعار.
- **مولَّدة بالذكاء الاصطناعي (Higgsfield) اعتماداً على الصور الحقيقية:** فيلم الافتتاحية (`assets/img/film/` و `film-poster`) وصور بطاقات المميزات `feat-1` إلى `feat-6`. تظهر في الصفحة مع عبارة «مشهد توضيحي» / «الصور توضيحية». بوابة المستودع في أول الفيلم متخيَّلة وليست صورة للمدخل الفعلي.
- `film-real` هي الصورة الحقيقية للوحدة C-06 بقياساتها موضوعة فوق آخر لقطة في الفيلم؛ الأرضية أمامها والجدار فوقها امتداد مولَّد.

لإعادة تقطيع الفيلم بعد تغيير لقطة في `_src/gen/` (يحتاج ffmpeg و Pillow و numpy، و OpenCV لتركيب الصورة الحقيقية):

```bash
python3 _src/film.py && python3 _src/build.py
```

الفيلم يعمل على الهاتف بالوضع العمودي فقط. من يفعّل «توفير البيانات» في متصفحه يرى الصفحة بدون الفيلم وببطاقات المميزات المرسومة.

## النشر

المجلد يعمل على أي استضافة ملفات ثابتة (Netlify، GitHub Pages، أو مجلد داخل موقع الشركة). لا يحتاج خادماً ولا قاعدة بيانات.

لتظهر صورة المعاينة عند مشاركة الرابط في واتساب، ابنِ الصفحة بالرابط النهائي:

```bash
python3 _src/build.py --base https://example.com/profile/
```

لصفحة معاينة واحدة تعمل لحالها (الصور مدمجة داخلها):

```bash
python3 _src/build.py --artifact مجلد_الإخراج
```

## روابط مفيدة

- `index.html#en` أو `?lang=en` يفتح النسخة الإنجليزية.
- `?lite=1` يفتح الوضع الخفيف بدون مجسّمات ولا فيلم (يُفعَّل تلقائياً على الأجهزة الضعيفة، ومن القائمة يدوياً).
- `?film=0` يعرض الممر المجسّم بدل الفيلم على الهاتف.

## الخصوصية

الصفحة لا تجمع بيانات ولا ترسل شيئاً لأي خادم. رسالة واتساب تُعرض للزبون كاملة قبل الإرسال وفيها اختياراته فقط.
