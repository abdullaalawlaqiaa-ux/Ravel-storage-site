# الملف التعريفي – Ravel Storage

ملف تعريفي من 8 صفحات بمقاس الهاتف (1080 × 1350) للإرسال عبر واتساب.

- `Ravel-Storage-Profile-AR.pdf` – النسخة الجاهزة للإرسال.
- `index.html` – النصوص والأسعار (جدول الأسعار في القسم رقم 6).
- `style.css` – الألوان والخطوط والمقاسات.
- `img/` – الصور والشعار. `fonts/` – الخطوط.

## التحديث
عدّل `index.html` ثم أعد بناء الـ PDF:
```bash
node build.js
```
`bake-u1.js` يعيد كتابة ملصقات الأبعاد على صورة وحدة 1 م² من `img/u1src.jpg`.
