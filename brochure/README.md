# الملف التعريفي – Ravel Storage

ملف تعريفي من 8 صفحات بمقاس الهاتف (1080 × 1350) للإرسال عبر واتساب.

- `Ravel-Storage-Profile-AR.pdf` و `Ravel-Storage-Profile-EN.pdf` – النسختان الجاهزتان للإرسال (عربي وإنجليزي).
- `index.html` (عربي) و `index-en.html` (إنجليزي) – النصوص والأسعار (جدول الأسعار في القسم رقم 6). أي تغيير في الأسعار يُكرَّر في الملفين.
- `style.css` – الألوان والخطوط والمقاسات.
- `img/` – الصور والشعار. `fonts/` – الخطوط.

## التحديث
عدّل الملفين ثم أعد بناء النسختين:
```bash
node build.js
```
`bake-u1.js` يعيد كتابة ملصقات الأبعاد على صورة وحدة 1 م² من `img/u1src.jpg`.
