# Ravel Storage — نظام تصوير الوحدات بمقاسات حقيقية

نظام يبني كل وحدة تخزين كمجسّم ثلاثي الأبعاد بالمتر الحقيقي داخل **Blender**، ويتحقق من مقاساتها آلياً، ثم يطلع صورة واقعية من مدخل الوحدة.

## المخرجات لكل وحدة (`output/<رقم الوحدة>/`)
| الملف | الوصف |
|---|---|
| `U01_clean.png` | الصورة النظيفة بدون مقاسات (3000×4000) |
| `U01_annotated.png` | نفس الصورة مع أسهم المقاسات، والسهم مرسوم على الموضع الحقيقي من المجسّم |
| `U01.blend` | المجسّم القابل للتعديل (يفتح في Blender المجاني) |
| `verification.json` | تقرير التحقق: العرض، العمق، المساحة، المربّع، الوحدة فاضية، بيانات الكاميرا |

## الملفات
- `config/units.json` — **كتالوج المقاسات المعتمدة** (داخلي صافي). أي وحدة جديدة تضاف هنا بعد تأكيد المالك.
- `config/facility.json` — مواصفات البناء المشتركة (ألواح، حديد مجلفن، أبواب، ألوان).
- `config/camera.json` — إعداد الكاميرا الموحّد لكل الوحدات.
- `scripts/build_unit.py` — يبني الوحدة، يتحقق من المقاسات، ويرندر.
- `scripts/materials.py` — الخامات (ألواح عازلة، مجلفن، خرسانة، ستانلس).
- `scripts/annotate.py` — يطلع النسخة النظيفة والنسخة المقاسة.
- `render_unit.py` — أمر واحد يسوي كل شي.

## طريقة الكاميرا (ثابتة لكل الوحدات)
- واقف في الممر على بعد 1.75 م من واجهة الوحدة، والعين على ارتفاع 1.60 م.
- عدسة 26 مم (نفس الكاميرا الرئيسية للجوال)، **بدون** عدسة واسعة أو عين سمكة.
- الكاميرا مستوية، فالخطوط العمودية تطلع عمودية، والأرضية تبان من عتبة الباب.

## التشغيل
```bash
pip install -r requirements.txt
python3 render_unit.py U01 --preview   # معاينة سريعة
python3 render_unit.py U01             # الجودة النهائية
```

## قواعد ثابتة
- المقاسات داخلية صافية، وما تتغير لأي سبب.
- الصورة المقاسة تعرض **الارتفاع المسموح** فقط، ولا تعرض ارتفاع الجدار.
- أي مقاس غير مؤكد من المالك ما يتكتب كمقاس دقيق.
- الوحدات فاضية، إلا إذا انطلب غير كذا.
